Newsletters prêtes à l'emploi

5 newsletters correspondant aux 5 axes du programme, prêtes à être envoyées via Brevo

Comment utiliser ces newsletters avec Brevo

  1. Cliquez sur "Voir" pour prévisualiser la newsletter
  2. Cliquez sur "Copier HTML" pour copier le code source
  3. Dans Brevo, créez une nouvelle campagne email
  4. Choisissez l'éditeur "Code HTML" et collez le contenu
  5. Remplacez {{unsubscribe_url}} par la variable Brevo correspondante
  6. Testez et envoyez !
